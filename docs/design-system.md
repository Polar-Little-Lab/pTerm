# Polar Night — Harbor 디자인 시스템

북극곰의 둥근 형태와 극지의 대비를 작업 도구의 언어로 사용한다. 자체 제작 SVG 북극곰 심벌을 사용하며 기존 제품의 리소스를 복제하지 않는다.

## 색과 위계

- Snow `#F5F8FB`: 기본 작업 화면. Glacier `#EDF2F7`: 탐색 패널.
- Ink `#172B42`: 본문. Slate `#61758A`: 보조 설명.
- Polar blue `#386AE8`: 선택·주요 작업. Ice `#E5EDFF`: 선택 배경.
- Midnight `#101D30`: 터미널. Mint `#19836C`: 연결됨.
- 오류는 붉은 작은 상태 카드로 표시하고 대상·다음 행동을 함께 제공한다.

## 레이아웃과 조작

248px 고정 탐색 패널 → 작업 헤더 → 세션 탭 → 작업 영역. 첫 화면은 호스트 라이브러리다. 광고형 hero와 기능 소개 카드를 제거한다. 검색은 이름·주소·사용자·그룹·태그를 검색한다. 즐겨찾기/그룹은 실제 필터다.

8px 간격 체계, 컨트롤 높이 36~40px, 카드 모서리 12px, 모달 18px. 아이콘은 lucide 18px/1.7 stroke. 본문 13~14px, 섹션 제목 18~24px. 상태는 색과 텍스트를 함께 사용한다.

검색 포커스는 input 자체가 아닌 컨테이너에 표시한다. 아이콘 버튼에는 접근 가능한 이름을 붙인다. modal은 Escape와 focus trap을 제공한다. 위험 작업은 대상 표시 후 확인한다. 좁은 창에서는 카드 grid가 축소되고 주 작업 영역은 독립적으로 스크롤한다.

## 제품 흐름

Vault 잠금 해제 → 호스트 선택/추가 → 인증 → 서버 지문 확인 → 터미널/SFTP. 저장 성공 전 UI에 저장 완료를 표시하지 않는다. 이전 평문 호스트는 암호화 저장 성공 후에만 이전 항목을 제거한다. 잠금은 활성 연결을 종료하고 메모리의 호스트·명령을 비운다.

북극곰은 브랜드와 빈 상태에서만 사용한다. 터미널·파일 목록의 가독성을 방해하는 장식은 두지 않는다.

## 0.2.1 — 제품 구분과 연결 폼

제품명은 **Polar SSH**, 공통 브랜드는 Polar, 용도는 SSH다. 후속 앱은 `Polar + 용도`와 용도별 중심 심벌로 구분한다. SSH 아이콘은 남색 터미널 창과 큰 `>_`, 작은 북극곰 브랜드 표식을 결합한다. 단순 곰 얼굴은 빈 상태 일러스트로 사용한다.

연결 폼은 42px 입력 높이와 동일한 포커스 테두리를 사용한다. 포트는 스피너 없는 numeric text input이며 1–65535 검증, 비밀번호/SSH 키는 native radio 의미를 가진 두 카드로 선택한다. 비밀번호 표시 버튼은 제출하지 않는 독립 버튼이며 인증 방식 전환 시 비밀번호와 표시 상태를 초기화한다.

사용자 데이터 연속성을 위해 bundle identifier `dev.harbor.ssh`와 Keychain namespace는 유지했다. 사용자에게 보이는 앱 이름, 창 제목, Dock 아이콘, 웹 제목, 터미널 배너는 Polar SSH로 변경했다.

## 0.2.2 — 통합 심벌

터미널 창과 곰 배지를 분리한 아이콘을 교체했다. 북극곰의 흰 실루엣 안에 짙은 남색 `>_`를 배치해 하나의 심벌로 만든다. 배경은 극야의 남색, 실루엣은 눈과 얼음의 색을 사용한다. 작은 크기에 불필요한 창 테두리·점·배지를 제거했다. `app/icon.svg`를 앱 아이콘 생성과 React 로고의 단일 원본으로 사용한다. 이전 시안은 `docs/assets/polar-ssh-icon-previous.svg`에 보관했다.

## 0.4.3 터미널 작업 화면

터미널 화면은 대시보드의 카드처럼 취급하지 않는다. 상시 표시 UI는 42px 탭 바 한 줄로 제한한다. 호스트 탐색은 겹침 패널, 부가 기능은 접을 수 있는 도구줄로 제공한다. 세션 탭만 가로 스크롤하고 새 탭·검색·도구 진입점은 항상 보인다. 터미널에서는 기존 navy 배경과 연한 blue 활성 표시를 사용하며, 라이브러리/폼은 기존 snow 테마를 유지한다.
