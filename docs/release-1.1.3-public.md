# pTerm 1.1.3

- 호스트 편집과 SFTP 버튼에 공통 보조 버튼 스타일을 적용했습니다.
- 고급 연결·전송 토글과 펼친 설정을 SSH/SFTP 버튼 위에 배치했습니다.
- 개인 키 파일 경로·읽기 오류를 키 암호 오류로 취급하던 흐름을 수정했습니다. 파일 오류는 원인을 표시하며 불필요한 암호 입력창을 열지 않습니다.
- SSH 인증 안내를 짧게 정리했습니다. SFTP는 기존 SSH 세션 또는 호스트에 저장한 SSH 인증을 사용합니다.

Apple Silicon Mac용 ZIP입니다. 기존 앱을 종료하고 교체하세요. Developer ID 서명·공증 및 실제 사용자 Mac의 Keychain 승인창 검증은 포함하지 않습니다.
