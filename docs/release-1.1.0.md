# pTerm 1.1.0 출시 준비

상태: 기능 구현과 자동 검증을 통과한 소스가 main에 통합됐다. 이 문서는 앱 배포 완료 공지가 아니다. 현재 공개 다운로드는 v1.0.0이다.

## 배포에 포함할 기능

자동 파일 기록·회전·RTF 내보내기, 설정 상속, 명령 트리거, SSH 연결 후 명령, 다중 전송, 터널, 시리얼, 저장 연결·인증 프로필, Python/Node 세션 자동화. 사용법과 외부 엔진 의존성은 [터미널 도구](terminal-tools.md), [연결·실행](native-connections.md)에 설명한다.

## 출시 순서

1. 버전 메타데이터와 화면 표시를 1.1.0으로 맞추고 macOS CI를 통과한다.
2. Apple Silicon Mac에서 `./scripts/app-build`로 배포 앱을 만들고, 실제 앱의 시작·SSH·SFTP·로그 저장·종료를 확인한다. 기존 데이터와 Keychain 호환성을 확인한다.
3. 앱 서명 상태와 ZIP 무결성을 확인하고 `pTerm-1.1.0-macos-arm64.zip` 및 SHA256SUMS.txt를 생성한다. Developer ID 서명·공증 여부를 실제 상태대로 명시한다.
4. 검증한 커밋에 v1.1.0 태그와 GitHub 릴리스를 만들고 앱 ZIP·체크섬을 첨부한다. 기존 1.0.0 파일은 유지한다.
5. Polar Apps의 pTerm 버전·변경 이력·기능 설명과 다운로드 링크를 실제 릴리스 자산으로 갱신한다. 설치 파일 없이 버전 표시만 1.1.0으로 바꾸지 않는다.

현재 CI는 테스트와 프런트엔드 빌드를 수행하며 배포 앱 ZIP 생성·서명·공증·업로드는 하지 않는다. GUI 수동 확인과 배포 앱 검증은 아직 남아 있다.

## 다음 개발 범위

1. 빠른 명령 트리·별칭: 저장·편집·검색·실행 대상 확인 흐름.
2. 그룹 일괄 연결·시작 세션: 진행 상태·부분 실패·취소.
3. 인코딩·영구 강조 규칙, 이후 X/Y/ZMODEM·ASCII 전송.

후속 기능은 별도 feat 브랜치와 PR로 진행한다. 1.1.0 배포 후 오류 수정은 1.1.x, 추가 기능 묶음은 1.2.0을 기준으로 관리한다. 전체 Xshell 기능 대응 완료를 뜻하지 않는다.
