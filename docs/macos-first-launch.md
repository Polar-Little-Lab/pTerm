# macOS에서 pTerm 처음 실행하기

대상: pTerm 1.0.0 · Apple Silicon Mac · 업데이트: 2026-10-25

## “Apple은 악성 코드가 없음을 확인할 수 없습니다”가 표시되나요?

pTerm 1.0.0은 Apple Developer ID 서명과 Apple 공증을 받지 않은 배포본입니다. 다운로드한 앱을 처음 열 때 macOS가 실행을 차단할 수 있습니다.

이 메시지는 Apple이 앱의 안전성을 확인하지 못했다는 뜻입니다. 이 문구 자체가 악성 코드가 검출되었다는 뜻은 아니지만, 다운로드한 파일의 안전성을 보증하는 것도 아닙니다. 아래 절차는 [pTerm 공식 GitHub 릴리스](https://github.com/Polar-Little-Lab/pTerm/releases/tag/v1.0.0)에서 받은 앱에 적용하세요.

## 해당 앱만 허용해서 실행하기

1. 릴리스에서 `pTerm-1.0.0-macos-arm64.zip`을 다운로드하고 압축을 풉니다. `Source code` 파일은 실행 앱이 아닙니다.
2. `pTerm.app`을 **응용 프로그램(Applications)** 폴더로 옮깁니다.
3. 앱을 더블클릭합니다. 위 경고가 나오면 **완료**를 눌러 닫습니다. **휴지통으로 이동**은 누르지 않습니다.
4. Apple 메뉴에서 **시스템 설정 → 개인정보 보호 및 보안**을 엽니다.
5. 아래로 스크롤해 **보안** 영역에서 pTerm 실행이 차단되었다는 안내를 찾습니다.
6. 해당 안내 옆 **그래도 열기**를 누릅니다. macOS 버전에 따라 버튼 문구가 다를 수 있습니다.
7. macOS가 요청하면 Mac의 사용자 암호 또는 표시되는 인증 방법으로 승인합니다.
8. 확인 창에서 **열기**를 선택합니다.

이후에는 해당 앱이 예외로 등록되어 일반적으로 더블클릭으로 실행됩니다. 위 절차는 [Apple 공식 지원 안내](https://support.apple.com/ko-kr/102445)를 따릅니다. Mac 전체의 보안 기능을 끄는 명령은 필요하지 않습니다.

## 그래도 열기 버튼이 보이지 않아요

앱을 실제로 한 번 열어 차단 메시지가 나타난 뒤 설정을 확인하세요. 응용 프로그램 폴더의 앱을 다시 더블클릭하고 **개인정보 보호 및 보안** 화면을 다시 확인합니다.

회사나 학교에서 관리하는 Mac은 관리 정책 때문에 설정을 변경할 수 없을 수 있습니다. 이 경우 관리자에게 앱 실행 허용을 요청하세요. [Apple 안내](https://support.apple.com/ko-kr/102445)

## SSH 비밀번호를 입력하는 건가요?

아닙니다. 첫 실행 승인에 필요한 인증은 **이 Mac에서 앱을 실행하도록 허용하는 인증**입니다. 원격 서버의 SSH 비밀번호를 입력하는 단계가 아닙니다.

앱이 열린 뒤 저장된 호스트·명령을 열 때 요청되는 **키체인 승인**, 원격 서버에 연결할 때 요청되는 **SSH 인증**도 각각 별도 과정입니다. 로컬 터미널은 저장된 항목의 잠금을 해제하지 않고 사용할 수 있습니다.

## 다른 종류의 경고가 나와요

“컴퓨터를 손상시킬 것입니다”, “악성 코드가 감지되었습니다”, “앱이 손상되었습니다”는 이 문서의 **확인할 수 없음** 경고와 다릅니다. 같은 절차로 무조건 실행하지 말고, 정확한 경고 문구와 다운로드 출처를 확인하세요. [경고 유형별 Apple 설명](https://support.apple.com/ko-kr/102445)

## 다운로드 파일 확인하기

릴리스에 제공된 `SHA256SUMS.txt`와 ZIP 파일을 같은 폴더에 두고, 터미널에서 그 폴더로 이동한 다음 아래 명령으로 체크섬을 비교할 수 있습니다.

```sh
shasum -a 256 -c SHA256SUMS.txt
```

해당 ZIP에 `OK`가 표시되는지 확인하세요. 체크섬 비교는 공개된 배포 파일과 같은지 확인하는 절차이며 Apple 공증이나 악성 코드 검사를 대신하지 않습니다.

앱이 열리면 [사용 가이드](user-guide.md)의 로컬 터미널·SSH·SFTP 사용 방법으로 이어가세요.
