pTerm 1.1.1은 연결 화면과 스크롤 동작을 개선합니다.

- 호스트 카드/이름 클릭 시 주소·인증·상태와 연결 버튼을 간결하게 표시
- 같은 모달에서 고급 연결·전송으로 전환하고 호스트 정보를 자동 입력
- 카드의 연결 버튼으로 바로 접속하며, 연결된 호스트는 기존 터미널로 이동
- 고급 인증·연결 저장·인증 프로필 관리를 기본적으로 접기
- 제목과 실행 버튼을 고정하고 긴 설정 본문만 스크롤
- 접힌 설정의 키보드 포커스와 시리얼 탐색 시점 개선

## 다운로드

**pTerm-1.1.1-macos-arm64.zip**을 받아 압축을 풀어 pTerm.app을 실행하세요. Apple Silicon Mac용입니다. Source code는 설치 파일이 아닙니다. 기존 앱을 종료한 뒤 교체하세요. 기존 저장소와 Keychain 식별자는 유지합니다.

앱은 ad-hoc 서명이며 Apple Developer ID 서명·공증은 포함하지 않습니다. [첫 실행 안내](https://github.com/Polar-Little-Lab/pTerm/blob/v1.1.1/docs/macos-first-launch.md)를 참고하세요. SHA256SUMS.txt로 파일 무결성을 확인할 수 있습니다.

자동 테스트, macOS 앱 빌드, ARM64 아키텍처·버전·서명·ZIP·체크섬을 검증합니다. 실제 Mac 화면에서 스크롤 감각을 확인하는 수동 검증은 별도입니다.
