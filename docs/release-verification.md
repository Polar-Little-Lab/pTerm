# pTerm 1.0.0 검증

2026-10-25 · macOS Apple Silicon

- JavaScript 회귀 테스트 69개와 React 상호작용 테스트 1개 통과.
- Rust 테스트 35개 통과, 별도 실행이 필요한 키체인·장시간 시험 4개 제외.
- 격리된 로컬 PTY, 루프백 SSH/SFTP, 인증 실패, 암호화 키, 출력·프로세스 정리 시험 포함.
- 프런트엔드 TypeScript/Vite 프로덕션 빌드 통과.
- 앱 패키지·Cargo·Tauri·화면 버전 모두 1.0.0.
- 기존 Vault 경로·키체인 서비스·테마 저장 키 유지.

실제 사용자 Vault/키체인을 열거나 자격증명을 변경하지 않았습니다. 기존 가이드 이미지는 Polarsh의 네이티브 촬영 기록이며 pTerm 이름으로 재촬영하지 않았습니다. Windows/Linux 앱은 이번 릴리스에 포함하지 않습니다.
