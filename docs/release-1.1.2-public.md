# pTerm 1.1.2

- 터미널 탭의 +에서 세션·호스트·새 연결을 선택합니다. 중복 돋보기와 상단 빠른 전환·기타 연결 버튼을 제거했습니다. ⌘ K 단축키는 유지합니다.
- 호스트에서 SSH 터미널 또는 SFTP 파일 전송을 바로 선택합니다. SFTP는 같은 SSH 인증과 경유 경로를 사용하고 기존 연결을 재사용합니다.
- 호스트 기본 정보를 유지하면서 고급 연결·전송을 토글로 펼칩니다.
- 저장소 잠금 해제 중 키체인 이름과 ACL 설명을 수정하지 않도록 변경했습니다. 저장된 SSH 키 암호 재사용을 회귀 검증하고 암호 입력 안내를 보완했습니다.

Apple Silicon Mac용 ZIP입니다. 기존 앱을 종료하고 새 앱으로 교체하세요. Developer ID 서명·공증은 포함하지 않습니다. macOS 승인창 횟수는 실제 사용자 Keychain 상태에 따라 달라지며, GUI에서의 재현 검증은 아직 수행하지 않았습니다.
