# 터미널 도구 사용 안내

이 문서는 `feat/macos-terminal-workflows`의 개발 중 기능을 설명합니다. v1.0.0 배포 앱에는 포함되어 있지 않습니다.

상단 **터미널 도구**를 누르거나 **⌘ K**에서 기능 이름을 검색합니다. 터미널 검색은 **⌘ F**로도 열 수 있습니다.

## 작성과 다중 전송

명령을 작성하고 연결된 세션을 선택한 뒤 **전송 대상 확인 → 확인한 대상에 전송**을 누릅니다. 전송 직전에 연결이 종료된 세션은 제외됩니다. 붙여넣기에 줄바꿈이 포함되면 셸에서 명령이 실행될 수 있습니다. 전송 결과는 원격 명령의 성공 여부를 뜻하지 않습니다.

## 검색

현재 세션의 스크롤백을 검색합니다. 대소문자와 정규식을 선택할 수 있으며 Enter/Shift+Enter 또는 이전/다음 버튼을 사용합니다. 결과는 최대 2,000개입니다. 오래 걸리는 정규식은 500ms 후 종료합니다. 이미 스크롤백에서 제거된 출력은 검색하지 않습니다.

## 기록과 재생

**기록 시작** 이후의 수신 출력만 메모리에 보관합니다. 최대 1 MiB 또는 4,096개 청크이며, 초과 시 오래된 기록을 버리고 표시합니다. 일반 로그, Hex, 재생용 JSON으로 저장할 수 있습니다. **로그 다시 보기**는 pTerm JSON 로그를 읽기 전용으로 순서대로 표시합니다. 원본 출력 시간 간격을 재현하지는 않습니다.

기록에는 서버가 출력한 민감한 정보가 포함될 수 있습니다. 세션을 닫기 전에 필요한 기록을 저장하세요.

## 자동화

JSON 배열의 세 가지 단계가 있습니다.

```json
[
  {"send":"echo ready\n"},
  {"expect":"ready","timeout":10000},
  {"wait":500}
]
```

- `send`: 현재 세션에 문자열을 붙여넣습니다.
- `expect`: 최근 전송 이후의 출력에 문자열이 나타나기를 기다립니다. 기본 10초, 최대 60초입니다.
- `wait`: 최대 30초까지 대기합니다.

최대 200개 단계, 전체 64 KiB입니다. 실행 전 대상과 단계를 확인합니다. 중지 버튼, 도구 화면 닫기, 연결 종료, 전송 실패, 출력 대기 시간 초과 시 실행이 멈춥니다. 이미 전달한 명령은 취소하거나 되돌리지 않습니다. JSON 시나리오 외에 Python/Node 세션 스크립트를 지원합니다. [연결·실행과 스크립트 안내](native-connections.md)를 참조하세요.

입력 기록은 비밀번호를 포함한 입력을 기록할 수 있으므로 필요한 작업 동안만 켜고 저장 전 검토하세요. 세션 단축키는 Ctrl+Option+문자로 등록합니다. 규칙과 기록은 현재 세션의 메모리에만 남습니다.

## 터널

연결된 SSH 세션에서 로컬·원격 포트 포워딩 또는 SOCKS5 동적 포워딩을 시작합니다. 로컬 포트 0은 빈 포트를 자동 선택합니다. 로컬 리스너는 `127.0.0.1`에 바인딩되고 원격 리스너도 서버에 `127.0.0.1` 바인딩을 요청합니다. 실제 서버의 GatewayPorts 정책이 영향을 줄 수 있습니다. 원격 리슨 포트는 1–65535로 지정합니다. SSH 종료 시 연결된 터널과 스트림도 정리됩니다.

SOCKS5는 무인증 CONNECT만 지원합니다. SOCKS4와 UDP는 제공하지 않습니다.

## 호스트 이전

⌘ K → **호스트·저장 명령 가져오기 / 내보내기**에서 JSON으로 이전합니다. Vault가 열린 상태에서 사용할 수 있습니다. 비밀번호와 서버 지문은 제외됩니다. 저장 명령에 직접 작성한 비밀 값은 자동 제거되지 않습니다. 가져오기는 미리보기 후 새 항목으로 추가하며 기존 항목을 덮어쓰지 않습니다.

## 화면과 닫기 보호

화면 탭에서 현재 세션의 글꼴 크기·커서·닫기 보호를 설정합니다. 닫기 보호는 탭/분할 영역을 실수로 닫는 것을 방지하는 옵션이며, 앱 종료·Vault 잠금·서버 연결 종료를 막는 보안 기능이 아닙니다. 이 설정은 다음 실행에 복원되지 않습니다.
