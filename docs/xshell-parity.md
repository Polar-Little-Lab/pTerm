# macOS 기능 확장 추적

목표: Xshell 상용판의 공개 기능을 macOS 우선으로 구현한다. 기능을 숨기기보다 기본 화면, 문맥 메뉴, 명령 검색, 상세 설정으로 나누어 접근한다. 구현과 실제 macOS 검증은 별도 상태로 기록한다. 기존 데이터와 Keychain 호환성을 유지한다.

## 상태
- 기존 구현(README 기준): 로컬/SSH, 탭/분할, 호스트 그룹·태그·검색, Bastion, 비밀번호/키/Agent, 지문 확인, SFTP, 저장 명령, 테마, Keychain 저장.
- 이번 변경: 여러 줄 클립보드 붙여넣기 확인·편집·취소. 대상 세션 표시, 연결 종료 시 폐기, 1 MiB 제한. 실제 macOS 클립보드 검증 대기.
- 아래 나머지 항목: 코드 감사 및 구현 대기. 목록에 있다는 이유로 지원 완료로 표시하지 않는다.

## 순서 및 범위
1. 입력: 작성 창, 다중 대상 전송, 붙여넣기 옵션, 키 매핑, 별칭, 빠른 명령 트리·가져오기·내보내기.
2. 세션: 속성 상속·일괄 변경, 인증 프로필, 세션 그룹, 시작 세션, 가져오기·내보내기, 아이콘, 탭 잠금, 재접속·keepalive.
3. 표시: 정규식 검색·강조, 인코딩, 글꼴 분리, 고정 크기·가로 스크롤, 선택·마우스·벨 옵션, 캡처·인쇄, Hex 보기.
4. 로그: 자동·수동 저장, 타임스탬프, 텍스트/RTF, 로그 해석기, 연결 추적, 보존 정책.
5. 네트워크: 로컬/원격/동적 포워딩, 즉석 규칙 변경·채널 표시, SOCKS/HTTP, 다단계 점프, IPv6, OpenSSH config.
6. 자동화: 트리거, 스크립트 실행·기록·인자, 로그인 스크립트, 알림. 무한 반복·중복 전송 방지.
7. 인증: OpenSSH CA, PKCS#11, Kerberos/GSSAPI, 키 생성·입출력, Agent forwarding, 수동/자동 잠금.
8. 파일: SCP, FTP, 전송 큐·지연·취소, X/Y/ZMODEM, ASCII 전송, 외부 편집기 연동.
9. 프로토콜: SERIAL, TELNET, RLOGIN, RDP, X11 forwarding. SSH1 등 구형 프로토콜은 구현 가능성과 라이브러리 지원을 조사해 호환 옵션으로 명시.
10. 플랫폼: CMD/WSL/ConPTY/SSPI/CAPI/Pageant는 Windows 의존 항목이다. macOS에서는 PTY·사용자 셸·Keychain·ssh-agent·플랫폼 인증으로 목적에 대응하며 동일 API 지원으로 표기하지 않는다. Xftp/Xmanager/Xlpd는 별도 제품으로 범위를 구분한다.

## UX 및 완료 기준
- 터미널 중심 화면 유지. 파일·로그·터널·자동화는 필요할 때 여는 패널.
- 모든 기능에 명시적인 메뉴 진입점과 검색 가능한 이름, 키보드 접근 제공.
- 다중 대상 작업은 대상 이름과 개수 표시. 실패를 성공처럼 표시하지 않는다.
- 각 항목은 저장/실행/취소/오류 처리, 회귀 테스트, 실제 macOS 검증을 마쳐야 완료.
- ARM64와 Intel 지원은 각각 빌드·실행 검증 후 표기.
