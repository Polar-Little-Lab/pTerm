# macOS 기능 확장 추적

목표: Xshell 상용판의 공개 기능을 macOS 우선으로 구현한다. 기능을 숨기기보다 기본 화면, 문맥 메뉴, 명령 검색, 상세 설정으로 나누어 접근한다. 구현과 실제 macOS 검증은 별도 상태로 기록한다. 기존 데이터와 Keychain 호환성을 유지한다.

## 상태
- 기존 구현(README 기준): 로컬/SSH, 탭/분할, 호스트 그룹·태그·검색, Bastion, 비밀번호/키/Agent, 지문 확인, SFTP, 저장 명령, 테마, Keychain 저장.
- 이번 변경: 여러 줄 클립보드 붙여넣기 확인·편집·취소. 대상 세션 표시, 연결 종료 시 폐기, 1 MiB 제한. 실제 macOS 클립보드 검증 대기.
- 아래 나머지 항목: 코드 감사 및 구현 대기. 목록에 있다는 이유로 지원 완료로 표시하지 않는다.

## 순서 및 범위
1. 입력: 작성 창, 다중 대상 전송, 붙여넣기 옵션, 키 매핑, 별칭, 빠른 명령 트리·가져오기·내보내기.
2. 세션: 속성 상속·일괄 변경, 인증 프로필, 세션 그룹, 시작 세션, 가져오기·내보내기, 아이콘, 탭 잠금, 재접속·keepalive.
3. 표시: 정규식 검색·강조, 인코딩, 글꼴 분리, 고정 크기·가로 스크롤, 선택·마우스·벨 옵션, 캡처·인쇄, Hex 보기.
4. 로그: 자동·수동 저장, 타임스탬프, 텍스트/RTF, 로그 해석기, 연결 추적, 보존 정책.
5. 네트워크: 로컬/원격/동적 포워딩, 즉석 규칙 변경·채널 표시, SOCKS/HTTP, 다단계 점프, IPv6, OpenSSH config.
6. 자동화: 트리거, 스크립트 실행·기록·인자, 로그인 스크립트, 알림. 무한 반복·중복 전송 방지.
7. 인증: OpenSSH CA, PKCS#11, Kerberos/GSSAPI, 키 생성·입출력, Agent forwarding, 수동/자동 잠금.
8. 파일: SCP, FTP, 전송 큐·지연·취소, X/Y/ZMODEM, ASCII 전송, 외부 편집기 연동.
9. 프로토콜: SERIAL, TELNET, RLOGIN, RDP, X11 forwarding. SSH1 등 구형 프로토콜은 구현 가능성과 라이브러리 지원을 조사해 호환 옵션으로 명시.
10. 플랫폼: CMD/WSL/ConPTY/SSPI/CAPI/Pageant는 Windows 의존 항목이다. macOS에서는 PTY·사용자 셸·Keychain·ssh-agent·플랫폼 인증으로 목적에 대응하며 동일 API 지원으로 표기하지 않는다. Xftp/Xmanager/Xlpd는 별도 제품으로 범위를 구분한다.

## UX 및 완료 기준
- 터미널 중심 화면 유지. 파일·로그·터널·자동화는 필요할 때 여는 패널.
- 모든 기능에 명시적인 메뉴 진입점과 검색 가능한 이름, 키보드 접근 제공.
- 다중 대상 작업은 대상 이름과 개수 표시. 실패를 성공처럼 표시하지 않는다.
- 각 항목은 저장/실행/취소/오류 처리, 회귀 테스트, 실제 macOS 검증을 마쳐야 완료.
- ARM64와 Intel 지원은 각각 빌드·실행 검증 후 표기.

근거: https://www.netsarang.com/en/xshell-all-features/ 및 https://www.netsarang.com/en/xshell-update-history/ (2026-10-26 조사).

## 2026-10-26 작업 현황

구현 및 프런트엔드 검증:
- 작성 창: 대상별 선택, 전송 전 확인, 연결 종료 대상 제외, 텍스트 내보내기.
- 검색: 스크롤백 문자열/정규식, 대소문자, 이전/다음, Worker 시간 제한.
- 기록: 수동 시작/중지, 수신 시각, 원시 Hex, 메모리 상한과 삭제, 파일 내보내기.
- 트리거: 청크 경계를 넘는 문자열 감지, 5초 중복 억제, 세션별 알림. 자동 명령·스크립트 실행은 미구현.
- 화면: 글꼴 크기, 커서, 스크롤백 저장/삭제. 현재 세션에만 적용.
- JSON 이전: 미리보기, 비밀번호/지문 제외, Bastion 참조 재매핑, 순환/형식 검증, 기존 데이터 보존.
- 메뉴: 상단 터미널 도구 및 빠른 전환 검색, 검색 단축키 Cmd+F.

네이티브 코드 구현, macOS 검증 대기:
- 기존 인증된 SSH 연결을 사용하는 로컬 포트 포워딩. 루프백 바인딩, 중지, 부모 연결 종료 정리, 오류 표시.
- 시스템 저장 대화상자와 파일 쓰기를 통한 텍스트 내보내기.
- macOS CI 작업 추가. 실행 성공 여부와 수동 UI 검증은 별도 확인해야 한다.

미구현: 원격 포워딩, RDP, SERIAL, TELNET/RLOGIN, X/Y/ZMODEM, FTP/SCP, PKCS#11/Kerberos/CA 인증 UI, 인증 프로필, Python/VBScript/JScript 실행, 자동 명령 트리거, 속성 상속, 세션 그룹, 인코딩·강조 규칙, RTF/자동 파일 기록 등. 전체 기능 완료가 아니다.


추가 구현:
- JSON 시나리오(send/wait/expect) 실행·취소, 출력 대기 시간 초과, 입력 실패 시 중단. Python/VBScript/JScript 호환 기능이 아니다.
- 입력 기록을 JSON 시나리오로 변환. 세션 메모리에만 보관하며 기록 여부를 명시한다.
- 세션별 Ctrl+Option+문자 키 매핑, 닫기 보호.
- SOCKS5 CONNECT 동적 포워딩. 로컬 루프백, IPv4/IPv6/도메인 주소. SOCKS4와 UDP는 미구현.
- pTerm JSON 로그의 읽기 전용 순서 재생. 원본 시간 간격 재현은 미구현.
- SFTP 양쪽 파일 이름 필터.

검증: 로컬 포워딩까지의 커밋 9e7fff5에 대해 GitHub macOS CI의 프런트엔드 빌드/테스트 및 Rust 테스트가 통과했다. 이후 SOCKS5·자동화 변경은 추가 CI 대상이다. 실제 GUI와 실서버의 종합 검증 완료를 의미하지 않는다.


검증 갱신: 0ebfcf3의 GitHub macOS CI도 성공했다. SOCKS5 협상 단위 테스트를 포함해 Rust 컴파일/테스트 및 프런트엔드 검증이 통과했다. 사용자 가이드는 `docs/terminal-tools.md`를 참조한다. RDP 등 미구현 항목은 그대로 남아 있다.
