# Frost 네이티브 화면 검증 기록

2026-10-25 · Polarsh 1.0.0

## 실행 조건

- 인증 정보 저장 구현 커밋: `983d489`. 촬영 중 저장 옵션 간격을 추가로 수정했고 `02-new-host`, `12-saved-credentials`는 수정 후 재빌드한 앱에서 촬영했습니다. 나머지 화면은 간격 변경의 영향을 받지 않습니다.
- 실제 Tauri release 앱 `Polarsh Guide`, 별도 식별자 `dev.polarsh.guide.20261025`. 제품 UI와 창 제목은 Polarsh입니다.
- 모든 촬영 화면은 Frost. 제목 표시줄과 탭 바가 같은 테마 색을 사용합니다.
- 촬영용 Keychain·SQLite만 사용했습니다. 사용자 호스트·SSH 키·비밀번호는 사용하지 않았습니다.
- 앱 재실행 후에는 새 로컬 셸 하나가 열렸으며 저장소를 연 뒤 실습 호스트와 저장 명령을 복원했습니다.

## 확인한 동작

| 동작 | 결과 |
| --- | --- |
| 비밀번호 저장 | 체크박스 선택 후 실제 SSH 인증 성공 |
| 같은 실행에서 재접속 | SSH 탭을 닫고 저장 호스트를 다시 열어 입력창 없이 연결 |
| 재실행 후 복원 | 비밀번호 입력란에 저장 상태 표시, 실제 값은 노출하지 않음 |
| 잘못된 비밀번호 | 의도적으로 잘못된 실습 값을 입력해 인증 실패·재입력 창 확인 |
| 비밀번호 교체 | 올바른 실습 값을 다시 입력해 인증·저장 성공 |
| Bastion | 연결된 Bastion을 통해 내부 서버에 실제 연결, 재실행 후 내부 서버의 저장된 인증 정보 사용 확인 |
| 저장 옵션 UI | 박스 아래 24px 여백, 설명 문구 들여쓰기, 삭제 버튼 표시 확인 |
| 인증 정보 삭제 | 버튼 표시는 네이티브 UI에서 확인. 삭제 동작은 기존 자동 테스트로 검증했으며 이번에 UI로 실행하지 않음 |
| 로컬 셸·분할 | `/tmp`에서 실제 셸 세 개 생성, 좌우 분할 후 오른쪽 상하 분할, `pwd`·`printf`·`date` 실행 |
| 저장 명령 | `디스크 사용량` / `df -h` 저장, `⌘ J` 선택 창 확인 |
| 빠른 전환 | 실습 SSH 세션·호스트 검색 확인 |

## 이미지와 제한

최신 게시용 이미지 11장은 실제 앱 창을 촬영해 PNG로 변환한 989×768px 파일입니다. 화면 내용이나 연결 성공 상태를 합성하지 않았습니다. 개인 기기 정보 노출을 피하려고 실습 로컬 셸의 프롬프트를 `polarsh`로 설정했습니다.

마우스 클릭·메뉴 확장 도구에서 native pipe 종료 오류가 반복되어 키보드로 가능한 동작을 수행했습니다. SFTP 및 배치 메뉴는 이번에 재촬영하지 못했습니다. 이전 두 이미지는 보관 폴더로 분리하고 최신 웹용 묶음과 본문에서는 제외했습니다. SFTP는 이전 실습 및 자동 테스트 이력이 있지만 이번 UI 촬영으로 재검증했다고 주장하지 않습니다.
