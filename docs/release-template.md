# PRODUCT VERSION

## 변경 사항
사용자에게 달라진 기능, 수정, 보안 변경을 이전 정식 버전 기준으로 기록합니다.

## 호환성 및 데이터
지원 OS·아키텍처, 데이터/설정 유지 또는 마이그레이션, 호환성 변경을 기록합니다.

## 다운로드
플랫폼별 파일명, 설치 방법, SHA256SUMS 확인 방법을 기록합니다.

## 검증
실제 성공한 테스트·빌드·서명·공증과 Actions 링크를 기록합니다. 예정과 완료를 구분합니다.

## 알려진 제한
서명되지 않은 플랫폼, 최초 승인, 미검증 환경 등 실제 제한을 기록합니다. 없으면 없음으로 표시합니다.
